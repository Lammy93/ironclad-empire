# Phase 3 backlog (ideas for the Phase 3 design round)

Collected from play-tests. Nothing here is designed or approved yet; each item gets designed with Zac in the
Phase 3 round.

- **Quest / tutorial tree** (play-test bugfix-1, 2026-11-03). Zac: "managing pawns professions isn't very clear on
  instruction either, i was hoping to have a quest tutorial tree similar to what all the mods 10 has".
  An in-game quest book in the style of ATM10's FTB Quests: a tree of steps that teaches the fortress loop
  (place campfire, assign professions, build, gather, craft, defend), with checkmarks as you go, and maybe rewards.
  Built into Ironclad Empire, not a dependency on FTB Quests. Bugfix-2 only added a clearer help box to the
  professions screen as a stop-gap.
- Pathfinding replacement (from the Phase 1 spec).
- Army stances (from the Phase 1 spec, issue #29).
- Reforged-style features rebuilt from scratch, and PvP / versus mode (agreed phase plan).
